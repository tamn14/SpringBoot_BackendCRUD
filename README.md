# 🌱 Spring Boot Backend Basic Project

A simple backend project using **Spring Boot** to demonstrate clean architecture with Entity, DTO, Service, and RESTful APIs.

---

## 🚀 Technologies & Features

### 🔧 TECH STACK

- ✅ **Spring Boot** – Main framework for building the backend
- ✅ **JPA Entity** – Used to map Java objects to database tables
- ✅ **DTO (Data Transfer Object)** – Used to transfer data between layers (e.g., backend → frontend)
- ✅ **JpaRepository** – Interface for interacting with the database (CRUD operations)
- ✅ **Service Layer** – Handles business logic, separates responsibilities from controller
- ✅ **RestController** – Creates REST APIs to interact with frontend or clients
- ✅ **ControllerAdvice** – Global error handling across all controllers
